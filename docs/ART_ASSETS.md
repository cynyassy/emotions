# Emotion Identifier Tool: Art Assets

Original artwork lives in `src/assets/emotion-art/`.

Imported starter set:

- `friendly-face.png` - warm face illustration, useful for the first "how are you feeling?" moment.
- `abstract-flower.png` - small abstract visual accent.
- `ground-yourself-plant.png` - plant illustration, useful for grounding and naming emotions.
- `ground-yourself-poster.png` - poster-style grounding artwork, reserved for future story sections.
- `red-heart-path.png` - small red heart path, useful for sharing or connection moments.
- `dual-emotion-dots.png` - minimal two-color face/dot artwork, useful for emotional contrast.

Direction:

- Use art as meaning, not decoration.
- Prefer one strong illustration per section over many scattered images.
- Keep the first screen readable; let the art support the story without making the page feel busy.
- Future images can replace current mockup cards and become the main visual storytelling layer.
